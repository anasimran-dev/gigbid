# Mobile-and-web GraphQL gateway

**Client:** a media company (synthetic).

## Problem
The client needed one flexible endpoint for the mobile and web apps and had no in-house capacity.

## What I did
I built the solution with GraphQL, Node.js, TypeScript. The work also involved something that runs the same on every machine.

## Result
The project replaced 37 REST endpoints with one schema.
